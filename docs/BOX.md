# Коробка игры

Каждая игра представлена на витрине коробкой от настольной игры. Это
обязательная часть приёмки, а не украшение: **игра без коробки на полку не
выходит**.

Форма одна на всех и живёт в платформе — полка читается полкой только тогда,
когда все коробки сделаны по одному образцу. Игра приносит цвета и рисунок
крышки.

## Как устроено

- `src/components/games/BoxFrame.tsx` — платформа: геометрия, торцы, донце,
  шов, блик, тень. Игра её не трогает.
- `src/games/<игра>/components/Box.tsx` — игра: пять цветов и содержимое
  крышки.
- Манифест игры отдаёт компонент в поле `Box`. Витрина рисует то, что в нём.

```tsx
import { BoxFrame, type BoxColors } from "@/components/games/BoxFrame";

const COLORS: BoxColors = {
  lid: "#d31450", // крышка
  side: "#c01047", // торцы крышки
  base: "#8e0a34", // донце, видное из-под крышки
  seam: "#7a0a2c", // шов по нижней кромке крышки
  rim: "#ff7aa8", // блик по верхним рёбрам
};

export function MyGameBox({ className }: { className?: string }) {
  return (
    <BoxFrame colors={COLORS} className={className}>
      {/* рисунок крышки в координатах 1000×620 */}
    </BoxFrame>
  );
}
```

## Геометрия — не трогать

Косоугольная проекция: смотрим чуть сверху и слева, вертикали остаются
вертикальными. Так торцы честные, а надпись на крышке ещё читается.

| Что                                | Значение     |
| ---------------------------------- | ------------ |
| Начало (дальний левый угол крышки) | `168, 110`   |
| Вдоль ширины                       | `472, -58`   |
| Вдоль глубины                      | `66, 252`    |
| Высота крышки                      | `51`         |
| Высота донца                       | `50`         |
| Поджатие донца                     | `10`         |
| Плоскость рисунка                  | `1000 × 620` |
| Холст                              | `880 × 540`  |

Рисунок ложится на крышку матрицей: прямоугольник `1000×620` превращается в
параллелограмм крышки. Поэтому надпись слегка скошена — как на настоящей
коробке под углом, а не наклеена сверху.

## Что обязано быть на крышке

Порядок сверху вниз — он и есть композиция:

1. **Надстрочник** — одна строка о том, что это за игра («игра для взрослой
   компании»). Мелко, приглушённым цветом.
2. **Вордмарк** — название крупно и двумя оттенками. Это главное на коробке и
   единственное, что обязано читаться с расстояния.

   Две строки — если название на них делится: «ПЛАТИ/ТУТКА». Одно слово в две
   строки не рвут — «ШАХ/МАТЫ» читается как оговорка; тогда строка одна, а два
   оттенка делят слово по смыслу внутри неё.

3. **Лента со слоганом** — короткая фраза на плашке, контрастной к крышке.
4. **Три бейджа** — игроки, возраст, длительность. Круг с числом и подпись
   под ним.
5. **Декор** — четыре-шесть предметов из мира игры по углам, полупрозрачных.
   Не абстрактные звёздочки: у платитутки это рубль, купюра и знак вопроса.

Метка 18+ на самой полке — отдельное поле манифеста (`adult`), а не рисунок
внутри коробки: полка показывает её сама.

## Правила, за которые уже платили

**Только встроенный SVG, не файл-картинка.** У `<img src="box.svg">` нет
доступа к шрифтам страницы: вордмарк съедет на системный шрифт, и коробка
развалится. Коробка — React-компонент со встроенным SVG.

**Читаемость проверяется в настоящем размере.** На полке коробка шириной около
280 точек. Всё, что не читается там, на коробке не нужно, каким бы красивым
оно ни было в макете. Проверяй на полке, а не на большом артборде.

**Рисунок обрезается краем крышки, и это делает `BoxFrame`.** Ничего
обрезать самой игре не надо: доску можно уводить за край, фигуры — ставить
вплотную. Пока декор был мелким, обрезки не было вовсе, и первый же рисунок
до края повис призраком рядом с коробкой.

**Не собирай коробку из HTML-элементов.** Стопка `div`-ов со смещением даёт
выпяченную шляпу без швов и торцов. Форма задаётся точками граней — она уже
задана, бери готовую.

**Цвета — из палитры своей игры**, а не из платформенной: коробка представляет
игру, и на полке она единственное цветное пятно своей игры.

## Приёмка

- [ ] Коробка отрисована и отдана в манифесте полем `Box`.

- [ ] Геометрия не переопределена.
