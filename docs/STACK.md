## Что здесь не как у людей

Эти места ломают ожидания чаще всего. Все они настоящие, проверены на этом
коде, и все уже кого-нибудь подводили.

**`src/proxy.ts` вместо `middleware.ts`.** В этой версии Next старое
соглашение объявлено устаревшим. Файл делает ровно то же: быструю развилку по
сессии до рендера.

**Документация фреймворка лежит в `node_modules/next/dist/docs/`.** Читать
надо её, а не память: версия свежая, и половина привычных рецептов здесь
неверна.

**Строка подключения Prisma — в `prisma.config.ts`, а не в схеме.** В схеме
`url` вызывает ошибку валидации.

**Схема Prisma — папка, а не файл.** `prisma/schema/platform.prisma` и
`prisma/schema/pricetitute.prisma`. Из-за этого пришлось закрепить явно две
вещи: путь к миграциям (иначе Prisma ищет их рядом со схемой) и путь вывода
клиента (иначе он съезжает на каталог глубже).

**Клиент Prisma генерируется в `src/generated/prisma` и не коммитится.**
Его делает `postinstall`. Пустая папка после свежего клона — это норма до
`npm install`.

**Сервер стартует из исходников через `tsx`.** `npm run build` собирает только
Next; `server.ts` не компилируется вовсе, поэтому в образ едет весь `src`.

**Env-схема ленивая.** Проверка срабатывает при первом обращении, а не при
старте, — иначе `next build` требовал бы боевых секретов. Пустая строка
считается отсутствующим значением: docker compose подставляет именно её.

**Один процесс.** Игровое состояние комнат живёт в памяти, поэтому
горизонтально масштабировать нельзя. Это записанное ограничение, а не
недосмотр (см. [DEPLOY.md](./DEPLOY.md)).

## Команды

```bash
npm run dev            # Next + сокеты на одном порту
npm run build          # сборка Next
npm test               # 225 тестов на родном раннере Node
npm run lint           # eslint, включая правило границы платформы и игры
npm run typecheck      # tsc --noEmit
npm run format         # prettier
npm run db:up          # postgres и mailpit в docker
npm run db:migrate     # migrate dev + generate
npm run db:seed        # сид платформы: идёт по реестру игр
```

Остальное — в [TESTING.md](./TESTING.md) и [DATABASE.md](./DATABASE.md).
