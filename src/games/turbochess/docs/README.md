# Турбо-шахматы

Мемный форк шахмат. Доска и фигуры узнаваемые, правила — нет: партия
играется в одном из шестнадцати режимов, и каждый режим ломает шахматы
по-своему. Где-то на доске одни кони, где-то за взятие фигуры соперник
пьёт стопку, где-то король при шахе телепортируется в случайную клетку,
а где-то играют вчетвером на доске в четыре раза больше.

Это **отдельная игра**, а не настройка шахмат. У неё свой код игры, своя
схема в базе, своя коробка на полке, свои фигуры и свой соперник-программа.
С шахматами она не делит ни строчки кода: платформа запрещает игре
импортировать другую игру (`eslint`, правило `no-restricted-imports`,
[docs/BACKLOG.md](../../../../docs/BACKLOG.md) A6). Всё, что взято из
шахмат, взято копией и переписано под свои правила.

## Что где лежит

| Путь          | Что там                                                                                              |
| ------------- | ---------------------------------------------------------------------------------------------------- |
| `protocol.ts` | Код игры, ключ общего зала, события сокета, форма снимка                                             |
| `manifest.ts` | Клиентская половина договора: витрина, адреса, коробка, знак                                         |
| `engine/`     | Свой движок правил: доска, ходы, запись, окончания, часы                                             |
| `menu.ts`     | Пункты игры в меню под аватаром                                                                      |
| `modes/`      | Каталог режимов, каркас (`rules.ts`: позиция, ручки, правила для игрока) и сами режимы               |
| `rooms/`      | Настройки комнаты: разбор формы (`settings.ts`), хранение (`store.ts`), запись партий (`matches.ts`) |
| `server/`     | Комната на своём движке, закрытая дверь вместо общего зала, серверный манифест                       |
| `bots/`       | Мозг соперника-программы: уровни, характеры, перебор, оценка, зевок, темп ([BOTS.md](BOTS.md))       |
| `components/` | Коробка, фигуры, доска, экран комнаты и экран трансляции, главная, форма своей партии                |
| `pages/`      | Что рисуется в `/r/<код>` и на экране трансляции                                                     |
| `scripts/`    | Смоук партии через сервер; лист фигур и его нарезка — руками                                         |
| `docs/`       | Эта папка                                                                                            |

Смоук — `npm run smoke:turbochess`, нужен живой `npm run dev` и база.
Знак, иконка вкладки и нарезанные фигуры (`pieces/`) лежат в
`public/games/turbochess/`, страницы игры — в `src/app/games/turbochess/`,
схема в базе — `prisma/schema/turbochess.prisma`.

## Что трогать нельзя

- **Платформенный код — ради этой игры ни строчки.** Единственное
  неизбежное исключение — обратные связи Prisma на `User`: их требует сам
  Prisma, иначе схема не соберётся.
- **В `GAME_SERVERS` дописываемся строго в конец.** Первый элемент —
  `defaultGameServer()`, на нём висит совместимость вкладок платитутки,
  открытых без параметра `game`.
- **Ключ общего зала** не `"global"` и не `"chess-lobby"` — они заняты.
- **Диапазон аватаров ботов** начинается с 1200: платитутка держит
  1000–1011, шахматы — с 1100, зазор оставлен на рост.
- **Ничего не рисуем в коде, пока рисунок не одобрен хозяином**
  ([docs/DESIGN.md](../../../../docs/DESIGN.md), правило D0). Коробка,
  знак и фигуры — блокирующий шаг, а не финальная полировка.

## Для агента

Правило импортов простое: наружу ходим через `@/…` и только в платформу,
к себе — относительными путями, в чужую игру — никогда. Нарушение ловит
`npm run lint`.

Проверки перед коммитом — в [docs/TESTING.md](../../../../docs/TESTING.md).
Коротко: `npm run typecheck`, `npm test`, `npm run lint`, `npm run build`,
потом смоук, если тронуты сокеты, комната или движок.

## Как оно сейчас

Играется по сети. Своя комната заводится с выбором режима и времени на ход,
соперник приходит по ссылке, зрители смотрят, экран показывает партию для
трансляции, сыгранные партии пишутся в базу. Работает первый режим — «Одним
видом фигур», всеми пятью видами; остальные пока играют обычные шахматы и в
форме помечены «скоро».
