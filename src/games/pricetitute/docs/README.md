# Платитутка

Игра про то, за какую сумму человек согласился бы это сделать. Ведущий
называет свою сумму втайне, остальные угадывают; очко забирает тот, кто
промахнулся меньше всех, — и только если мимо не больше чем вдвое.

Правила целиком — [SPEC.md](./SPEC.md).

## Где что лежит

```
src/games/pricetitute/
  engine/       правила: фазы, ставки, счёт, короны
  questions/    пул вопросов, паки, режимы, очередь
  bots/         режиссёр, реплики, аватары ботов
  leaderboard/  рейтинг и чемпионы
  rooms/        настройки партии и их хранение
  components/   экраны игры
  server/       движок для платформы: комната, манифест
  seed/         1100 вопросов и заливка
  scripts/      обслуживание: аудит вопросов, переименование
  protocol.ts   игровая часть контракта сокетов
  manifest.ts   договор с платформой, клиентская половина
```

Таблицы — в схеме `pricetitute`: `questions`, `rounds`, `round_bets`,
`scores`, `room_question_queues`, `room_settings`.

Страницы — в `src/app/games/pricetitute/`.

## Что трогать нельзя

- **Ключ общего зала `"global"`** — за ним в базе живые раунды и очки.
- **Ключ `pricetitute:hardcore:<code>` в localStorage** — смена заново покажет
  предупреждение всем, кто его уже принял.
- **Текст вопроса как ключ заливки.** Переписывать вопросы в базе можно только
  скриптом `db:rename-questions` и только до сида, иначе пул удвоится.
- **Адреса `/r/<code>` и `/r/<code>/tv`** — разосланы людям и вбиты в OBS.

## Для агента

Игра импортирует платформу, платформа игру — никогда. Если понадобилось
править платформенный код ради платитутки — скорее всего, код лежит не там.

Правки в правилах ловятся юнит-тестами, правки в сокетах и комнатах — только
смоуками. Что чем проверяется — в [TESTING.md](../../../../docs/TESTING.md).
